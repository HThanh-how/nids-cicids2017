# SOICT 2026 oral slides

Single-file slide deck for the SOICT 2026 oral presentation of paper 9222, "How Optimistic Is Your Intrusion-Detection Benchmark?". The deck is one self-contained HTML file (Three.js, works offline).

Live: https://hthanh-how.github.io/nids-cicids2017/

To open: download `soict2026-oral.html` and double-click it, or use the live link above.

Keys: arrows to move, F fullscreen, N speaker notes, S/M toggle scene options, P presenter window, ? help.
